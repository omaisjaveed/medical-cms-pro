# Medical-CMS-PRO 

A professional, full-stack Content Management System (CMS) designed for Chiropractic clinics. This project features a modern, high-performance frontend and a robust administrative dashboard for managing content, services, blogs, and media.

## 🚀 Features

- **Dynamic CMS**: Manage all website sections, services, and testimonials from a custom-built admin panel.
- **Media Library**: Advanced media picker supporting bulk uploads and centralized asset management.
- **Blog System**: Full-featured blog management with SEO-friendly structures.
- **Admin Dashboard**: Secure login with stats and inquiry management.
- **Modern UI/UX**: Built with React 19, GSAP animations, and Swiper for a premium feel.
- **SEO Optimized**: Dynamic meta settings and clean HTML structure.

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 19 (Vite)
- **Animations**: GSAP (GreenSock Animation Platform)
- **Styling**: Tailwind CSS / Custom CSS
- **Components**: Swiper, ReactQuill (Rich Text), Lightbox
- **Icons**: FontAwesome

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js (TypeScript)
- **Database**: MySQL with Sequelize ORM
- **Authentication**: JWT (JSON Web Tokens)

## 📁 Project Structure

```text
project-root/
├── frontend/     # React application (Vite)
└── backend/      # Node.js Express API (TypeScript)
```

## ⚙️ Setup Instructions

### Backend Setup
1. Navigate to `backend`
2. Install dependencies: `npm install`
3. Configure `.env` file (refer to `.env.example`)
4. Run migrations/seeders: `npm run seed` (if applicable)
5. Start server: `npm run dev`

### Frontend Setup
1. Navigate to `frontend`
2. Install dependencies: `npm install`
3. Configure `.env` with backend API URL
4. Start development server: `npm run dev`
